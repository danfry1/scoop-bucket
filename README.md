# scoop-bucket

A [Scoop](https://scoop.sh) bucket for danfry1's command-line tools.

## Usage

```sh
scoop bucket add danfry1 https://github.com/danfry1/scoop-bucket
scoop install hacker-news-tui
```

## Available apps

- [`hacker-news-tui`](https://github.com/danfry1/hacker-news-tui) — a delightful terminal UI for browsing Hacker News

Manifests are bumped automatically when a tool publishes a new release.
